# 動画生成スクリプト

## ⚠️ 一番大事なこと（注意事項）

**現状、わずか30秒足らずの動画を作るのも結構難しいです。**

その主な理由は以下の通りです：
- 30秒程度の動画を作るためには、一度に生成することはできず、**脚本を配列で用意して短尺動画をいくつか作る必要があります**。
- **APIが頻繁に落ちる**ため、生成プロセスが途中で失敗しやすくなっています。

[![デモ動画を見る](https://img.youtube.com/vi/Ojob-NSOqrk/hqdefault.jpg)](https://youtu.be/Ojob-NSOqrk)

## 準備

本スクリプトを実行するためには、`.env` ファイルに Gemini API key の登録が必要です。
API key は **Google AI Studio** で登録・取得が可能です。

1. ルートディレクトリに `.env` ファイルを作成します。
2. 取得したAPIキーを以下のように記述してください。

```
GEMINI_API_KEY=あなたのAPIキー
```

## スクリプトについて
- `generate_long_video.py`: 脚本を配列で用意し、複数の短尺動画を生成するスクリプト。
- `generate_short_video.py`: 単一の短尺動画を生成するスクリプト。
